GitHub Proxy

GitHub 仓库克隆与文件加速下载

输入后自动识别仓库或文件，实时生成加速链接和命令。

使用说明

  1. 替换域名：将链接中的 github.com 替换为当前部署域名，即可克隆仓库或下载文件。 https://你的域名/user/repo.git
  2. 添加前缀：将完整的 GitHub URL 放在当前站点地址后面，同样支持克隆和下载。 https://你的域名/https://github.com/user/repo.git

也可在上方粘贴链接，自动生成命令。Raw / Gist 链接请使用添加前缀的方式。
